## Tôi đã tự kiểm tra
Đây là task thiết kế, không có test để chạy lại. Tôi đã đọc và đối chiếu:
- `docs/agents/design/API_GD2.md` (toàn bộ, 560 dòng), `docs/agents/reports/T200.md`, `docs/agents/QUY_TRINH.md`, `docs/DAC_TA.md` (mục 1–5, mục 3 FR06, NFR06, NFR07), `docs/agents/design/QD_ZOD.md` §4.5.
- Code dùng để đối chiếu hợp đồng:
  - `apps/api/src/middlewares/validate.js`: `details` = `{ [issue.path.join('.') \|\| '_']: message }`, tối đa 50 mục.
  - `apps/api/src/middlewares/errorHandler.js`: định dạng `{ error: { code, message, details } }`.
  - `apps/api/src/modules/auth/routes.js`, `service.js`: cookie `nckh_rt` có `httpOnly`, `path=/api/auth`, `sameSite=lax`. Refresh xoay vòng token; nếu token đã thu hồi bị dùng lại thì thu hồi cả họ phiên. `publicUser` có `mustChangePassword`, không có phạm vi khoa.
  - `apps/api/src/middlewares/auth.js`: `requireAuth` nạp lại user từ DB ở mỗi request.
  - `packages/shared/src/enums.js`, `transitions.js`: chỉ có `TOPIC_STATUS_LABEL`, `FINAL_RESULT_LABEL`; không có `REQUEST_STATUS`, cũng không có nhãn cho vai trò, action, mức tương tự.
  - `apps/api/prisma/schema.prisma:41`: có `enum RequestStatus`.
