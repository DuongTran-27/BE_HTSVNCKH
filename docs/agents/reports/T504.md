# T504 – UI chuông thông báo, dashboard thống kê, xuất CSV, đề tài kẹt
- Agent: frontend-dev · Trạng thái: REVIEW · Ngày: 2026-11-05
- FR/NFR: FR08, FR13, FR14, FR16.5 · API_GD45 §8.1, §9 · API_GD2 §5.4

## Đã làm
- Chuông trong header (`NotificationBell`): `GET /notifications/unread-count`, `refetchInterval` 60 s (TanStack dừng khi tab ẩn), `aria-label` "Thông báo, N chưa đọc", ẩn khi phải đổi mật khẩu.
- `/thong-bao`: danh sách phân trang, lọc "Chỉ chưa đọc", đánh dấu từng thông báo / tất cả; bấm tiêu đề thì đánh dấu đã đọc rồi đi tới `link` (qua `safeNext`, chống open redirect).
- `/thong-ke`: bộ lọc lưu trên URL, biểu đồ Recharts cột/tròn, bảng (có `caption`, `scope`, dòng Tổng), nút "Xuất CSV". Biểu đồ, bảng, CSV dùng chung một chuỗi query `qs(params)`. `lecturerId` chỉ gửi với STAFF; "Nháp" không có trong bộ lọc trạng thái.
- Widget "Đề tài kẹt sau khi đóng đăng ký" (chỉ STAFF, đặt cuối `/thong-ke`): `GET /topics?status=WAITING_ADVISOR|HAS_ADVISOR&roundId&pageSize=100`, giữ item có `round.registrationOpen === false`.
- `api()` thêm tùy chọn `{ as: 'blob' }` để tải CSV qua client duy nhất (có Bearer, refresh 401). Tên file dựng ở FE: `thong-ke-<groupBy>-<yyyyMMdd giờ VN>.csv`.
- Cài `recharts@3.10.1` (ghim) vào `@nckh/web`.
