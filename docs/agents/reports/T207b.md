# Báo cáo T207b – Nhập CSV tài khoản (FR02)

- Task: T207b · Agent: BE · Phụ thuộc: T207a · Trạng thái đề xuất: chờ RV, BM

## Đã làm
- `POST /api/users/import/preview|confirm?facultyId=` (API_GD2 §3.2): thứ tự guard -> limiter 10/15 phút/user (mỗi route một limiter) -> `requireRole(ADMIN,STAFF)` -> validate query -> phạm vi STAFF (chỉ từ query) -> đọc multipart -> service. Người sai vai trò/ngoài phạm vi bị 401/403 trước khi file được đọc.
- Preview không ghi DB. Lỗi cấp file (sai loại/UTF-8/NUL, sai tiêu đề, rỗng, > `USER_IMPORT_MAX_ROWS`) -> 400 `VALIDATION_ERROR` `details.file`. Lỗi theo dòng `{row, field, message}` (`row` tính cả dòng tiêu đề, `field: null` cho lỗi cả dòng); `errors`/`preview` <= 100, `validCount`/`errorCount` là tổng thật (`errorCount` = số dòng lỗi).
- Kiểm: schema `userImportRowSchema` (shared), trùng trong file (mã không phân biệt hoa thường, email, dòng trùng hoàn toàn), trùng DB (1 truy vấn), lớp `isActive` thuộc khoa (1 truy vấn).
- Confirm: giữ `importLock` (kiểm và đặt cờ đồng bộ, nhả trong `finally`) -> kiểm lại từ đầu -> có lỗi: 400 `IMPORT_HAS_ERRORS` với `details` = báo cáo preview, không ghi gì -> băm trước transaction, tối đa 2 phép song song (`IMPORT_HASH_CONCURRENCY`) -> một transaction `{timeout 20000, maxWait 5000}`: `createManyAndReturn` + `createMany` AuditLog `USER_CREATE` (có `source: CSV_IMPORT`, không mật khẩu). P2002 -> rollback, 409 `DUPLICATE`. 200 + `Cache-Control: no-store`, `{createdCount, credentials}`.
- Shared: `csv.js` chuyển từ `apps/api/src/lib/csv.js` (git mv) sang `packages/shared/src/csv.js`, thêm `parseCsv`; `USER_IMPORT_HEADERS`, `USER_IMPORT_MAX_ROWS` (2000), `USER_IMPORT_MAX_BYTES` (1 MiB), `userImportRowSchema` ở `users.js`. `apps/api/tests/csv.test.js` chỉ đổi dòng import sang `@nckh/shared`.
- MINOR 1 (T207a-bao-mat-v2): `/api/auth/refresh` chỉ xóa cookie khi `e.status === 401`.
- MINOR 2: ca "refresh ‖ khóa tài khoản" trong `tests/security/T207a-vong1.test.js` không còn `expect(waitBlocked).toBe(true)` (chỉ chờ), khẳng định hậu quả `live == 0`. Chưa chạy đột biến bỏ `FOR SHARE` để xác nhận ca này đỏ vì còn token sống (xem Rủi ro).

- **Multer chưa có trong repo** (QD_ZOD §4.3 chọn `multer ^2.5.0`, nhưng task cấm đổi dependency). Tôi viết `lib/multipart.js` tối thiểu: đúng một file ở field `file`, giới hạn `fileSize` 1 MB (413), <= 7 phần, field <= 1 KB, chặn theo `Content-Length` và theo byte nhận, mọi dạng hỏng khác 400. Đọc cả body vào RAM (đã chặn). **Đề xuất cho kien-truc-su**: T403 thêm `multer ^2.5.0` và thay file này bằng wrapper QD §4.2 (route không đổi). Parser CSV tự viết trong shared (`parseCsv`), không thêm thư viện.
- `importLock` là cờ trong bộ nhớ, đúng 1 instance (ghi `shortcut` trong code).
- Giá trị CSV được lưu nguyên (không thêm tiền tố chống injection ở DB); chống injection áp dụng khi xuất (`escapeCell`/`toCsv`), FE dùng khi tải `credentials`.
