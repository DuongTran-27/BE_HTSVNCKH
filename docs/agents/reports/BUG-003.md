# BUG-003 – `db:test:reset` xóa DB do `DIRECT_URL` đã export trỏ tới
- Agent: devops · Trạng thái: REVIEW · Ngày: 2026-11-01
- FR/NFR: NFR08 · Làm chung vòng sửa 2 của T201 – chi tiết, bằng chứng đầy đủ: `reports/T201.md` mục "Vòng sửa 2"

## Nguyên nhân
`reset-test-db.js` chỉ kiểm host của `DATABASE_URL`, còn `prisma db push --force-reset` / `migrate reset` chạy trên `directUrl` (`DIRECT_URL`). `loadEnvFile` không ghi đè biến đã export, nên `DIRECT_URL` của DB dev đi qua chốt chặn.

## Đã sửa
- Mới `apps/api/scripts/test-db-guard.js`: lấy mọi tên biến `env("...")` trong `schema.prisma`; mỗi URL phải host cục bộ **và** tên DB kết thúc `_test` (chặn cả DB dev nằm trên localhost như `nckh_dev_qa`).
- `apps/api/scripts/reset-test-db.js` gọi chốt chặn trước mọi lệnh prisma; `apps/api/scripts/db-test.js` dùng chung hàm.
- Test thêm: `apps/api/tests/T201-db-helpers.test.js` (5 test cho chốt chặn). Test QA `T201-qa-isolation.test.js` không sửa.
