# BUG-004 – vitest chạy trên `DATABASE_URL` dev đã export
- Agent: devops · Trạng thái: REVIEW · Ngày: 2026-11-01
- FR/NFR: NFR08 · Làm chung vòng sửa 2 của T201 – chi tiết, bằng chứng đầy đủ: `reports/T201.md` mục "Vòng sửa 2"

## Nguyên nhân
`apps/api/vitest.config.js` nạp `.env.test` bằng `loadEnvFile` (không ghi đè) và không kiểm gì, nên biến DB dev đã export được dùng nguyên.

## Đã sửa
- `apps/api/vitest.config.js` gọi `assertTestDbEnv` (cùng chốt chặn với BUG-003, `apps/api/scripts/test-db-guard.js`) khi nạp config: bất kỳ URL nào `schema.prisma` dùng không phải DB `*_test` ở localhost → in lỗi tiếng Việt, `process.exit(1)` trước khi chạy test nào.
- Cùng vòng: `fileParallelism: false`, `globalSetup` thử kết nối một lần (`apps/api/tests/global-setup.js`), helper `resetData` (`apps/api/tests/db.js`).

## Bằng chứng chạy lệnh
```
$ DATABASE_URL=postgresql://u:p@db-dev.example.invalid:5432/nckh_dev npx vitest run tests/T201-db-test.test.js   (apps/api)

Bỏ biến đã export trong shell (vd. "unset DATABASE_URL DIRECT_URL") để dùng apps/api/.env.test.
exit=1
```
