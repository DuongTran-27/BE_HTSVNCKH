### Còn lại / rủi ro (thay mục vòng 0)
- **V2 từ PowerShell chưa chạy**: lệnh `powershell.exe -Command "npm run db:test:up"` bị hệ thống quyền của agent chặn. Mọi bằng chứng ở trên chạy từ Git Bash (DO v2 cũng đã thử Git Bash). Cần người dùng chạy một lần trong PowerShell (mục "Việc con người cần làm").
- **Bước 4.6 giả lập, không dùng `taskkill`**: `taskkill /F /IM postgres.exe` bị hệ thống quyền chặn (có thể giết postgres khác trên máy). Thay bằng: lưu `postmaster.pid` khi server đang chạy → `pg_ctl stop` → chép lại file pid cũ. Trạng thái tạo ra giống sau khi tiến trình bị kill (file pid trỏ PID đã chết, `pg_ctl status` = 3), và `down` xử lý đúng. Khác biệt duy nhất: kill thật có thể để lại shared memory/segment – Windows tự giải phóng khi tiến trình chết.
- **`npm run lint` đỏ**: ESLint chưa có trong repo – phạm vi T202. (Khi kiểm, `npx eslint --version` đã tải eslint 10.14.0 vào cache npx; không ghi gì vào repo.)
- **`npm test` gốc đỏ do `apps/web`**: 1 test `logout-guest-refresh.test.js` của frontend-dev đang làm dở. Phần T201 (shared + api) xanh.
- **`npm test` giờ cần DB**: 8 test DB của T201 FAIL nếu chưa `db:test:up` (cố ý, theo yêu cầu không skip âm thầm). Máy/agent khác phải chạy `npx -w @nckh/api prisma generate` (lần đầu) → `npm run db:test:up` → `npm run db:test:reset` trước `npm test`. T202 phải làm đúng thứ tự này trên CI. Nếu reviewer muốn `npm test` chạy được khi không có DB, cần quyết định riêng (ví dụ tách `test:db`) – tôi không tự thêm cơ chế skip.
